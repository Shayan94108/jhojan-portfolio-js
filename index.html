Diseno y desarrollo de paginas web

Soy Jhojan Sebastian y estoy aprendiendo a crear sitios web con HTML y CSS. En este portfolio muestro ejercicios en los que practico como organizar el contenido y crear paginas faciles de navegar.

En mi Portfolio encontraras una galeria con fotos de mis gatos. La cree para practicar como organizar imagenes con HTML y CSS. Si tienes una idea para una pagina web, puedes contarme que necesitas en la seccion de Presupuesto.

Mis servicios

Diseno paginas web con HTML y CSS, cuidando la organizacion del contenido y su presentacion.

  • Paginas para pequenos negocios. Reunen sus servicios, horarios y datos de contacto en un solo lugar.
  • Portfolios. Presentan cada trabajo con imagenes y una descripcion de lo que se hizo.
  • Paginas adaptadas a moviles. Ajusto el menu, el texto y las imagenes para que se lean bien en pantallas pequenas.

Sobre mi

Con este proyecto he practicado como organizar los archivos en carpetas, enlazar varias paginas y comprobar los datos de un formulario. Tambien he aprendido a mantener el pie de pagina al fondo de la ventana aunque haya poco contenido.

Mi objetivo es seguir mejorando y crear paginas claras, ordenadas y faciles de utilizar para tener un futuro aqui en espana.
